# 🐶 Highland Dog Chew – Full Stack eCommerce Platform

A production-ready full-stack MERN + Next.js eCommerce platform for selling premium Himalayan dog chews.

Built with modern technologies, secure authentication, Stripe payments, product category separation, and professional UI/UX.

---

## 🚀 Tech Stack

### 🖥 Frontend
- Next.js (App Router)
- React.js
- Tailwind CSS
- Lucide Icons
- Stripe.js

### ⚙ Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT Authentication
- Stripe Payment Gateway

---

## 📦 Features

### 🛍 Product System
- Dynamic product creation from Admin Dashboard
- Category-based filtering:
  - Yak Milk Chew
  - Puff Treat
  - Highland Mix
- Image gallery with thumbnail switching
- Size-based pricing
- Bundle discount system
- Subscription UI (frontend ready)
- Modern hover animations

---

### 💳 Secure Payment System
- Stripe Checkout integration
- Promo code support
- Order validation before payment
- Secure environment variable handling

---

### 👨‍💼 Admin Dashboard
- Add / Edit / Delete Products
- Upload product images
- Strict productType separation using enum
- Dynamic homepage product loading

---

### 🔐 Authentication
- JWT-based login system
- Protected admin routes
- Secure cookie handling

---
